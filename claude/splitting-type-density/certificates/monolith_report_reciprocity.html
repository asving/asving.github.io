## How the modules were produced (mechanical; proof text untouched)

`transform.py` is the old script with only its output path changed (and the manifest path made overridable); it maps
each accepted `theorem solution` file to `Theorems/Thm_SurfaceBlowupV2_<slug>.lean`: imports, `set_option` and `open`
preamble kept verbatim; `theorem solution` renamed to `theorem SurfaceBlowupV2.<slug>`; proof bodies never edited.
Child imports need no rewriting: a solution imports `Theorems.Thm_SurfaceBlowupV2_<child>`, which in this project *is*
the child's proved module. Helper declarations preceding the main theorem (34 of 133 files; the other 99 are the renamed
theorem alone) are wrapped in `namespace SolN<id> … end SolN<id>` with `open SolN<id> in` before the main theorem's
command; one file (N1191, `recip_scongr_exp_log`) declares helpers under `SurfaceBlowupV2.` and gets the extra
`open SolN1191.SurfaceBlowupV2 in`. No hoisted sections, no repeated depth-0 commands, no transform errors
(`transform_manifest_recip.json`). The 4 definition modules were copied verbatim from `blueprint/lean/Definitions/`.
`gen_monolith_recip.py` extended the certificate files: `Monolith/Main.lean` (+ `recip_main`), `Monolith/AxCheck.lean`
(+ 133 imports and `#print axioms`), `Monolith/StubCertify.lean` (1001 → 1134 names), and wrote
`Monolith/TypeDump_recip.lean` (the old `TypeDump.lean` code over the 133 new names).
